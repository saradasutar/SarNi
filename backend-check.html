If the check fails

  1. Google sign-in, permission denied or 404: Open the SarNi Apps Script project. Check Deploy → Manage deployments, its access setting, and whether the URL ends in /exec.
  2. Family Dashboard or another application: The frontend has the wrong deployment URL. Use the correct SarNi /exec URL and update both index.html and config.js.
  3. SarNi JSON, but wrong version: Save the backend code and deploy a new version of the existing web app. Do not run setupSystem(), reset passwords or create a new database.
  4. Correct SarNi JSON but polling still fails: Check whether the deployed code includes pollResultOutput_, and test Chrome Incognito to exclude browser blocking. The working editor code and the deployed version can differ.

This page cannot change your deployment or verify your password. If it fails, report the result and what the Apps Script endpoint displays. Do not share passwords, session tokens or Sheet contents.
