SarNi Family Expense — Frontend Updater

Use this file on your computer. It works offline, preserves your other dashboard features and does not upload your source files or passwords anywhere.

First back up the three existing frontend files from GitHub. Do not use old copies. Add the backend .gs file and route before enabling Family Expense.
Choose the index.html inside the q folder, not the dashboard root index.html.
Choose the main SarNi index.html from the repository ROOT, not q/index.html. This makes the updated link manager load without old browser cache.

After downloading: Upload each generated file to the SAME GitHub path, commit, and refresh your site. For the q folder, GitHub path must remain q/index.html. If GitHub Pages caches the old page, perform a hard refresh.
