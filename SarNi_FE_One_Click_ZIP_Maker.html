Step 4 · Upload extracted files to GitHub

  1. Unzip the SarNi-FE-Complete-Updated.zip that this page downloads.
  2. Open your SarNi GitHub repository.
  3. Choose Add file → Upload files, then drag the contents of the extracted folder (not the ZIP itself) and commit the update.
  4. Keep the existing repository and Pages settings. Do not upload the private Code.gs to GitHub.

Some GitHub upload screens do not accept nested folders by drag-and-drop. If they are in the existing repo, upload only the updated files directly; keep the others unchanged.
