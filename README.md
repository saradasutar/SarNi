# SarNi — Personal Life Centre (FE 20.3.0)

Only the minimal GitHub Pages assets are in this folder:
- `index.html` launches the existing native Apps Script dashboard
- `app-v20-3-0.js` application
- `styles.css` dashboard styling
- `favicon.svg` icon
- `build-version.json` release information
- `repair-login.html` optional browser recovery

`Code.gs` and `IndexApp.html` belong in the **private Apps Script** project, not public GitHub.
The native Apps Script IndexApp has its backend URL embedded already; there is no extra `config.js` needed for the current setup.

Do not upload the old `master-holdings` or `master-watchlist` CSV files to public GitHub. This GitHub site only contains frontend code.
