# SarNi 9.5+/10 acceptance checklist — targets only

1. Direct use: Expense entry in seconds, preserved context, no popup; Quick Diary directly available.
2. Search: Previous years searchable locally using All months; matched count/totals and print consistent.
3. Visual insights: Charts show real actual expense data, exclude recurring templates and plans, text legends, mobile cards.
4. Reports: All-month printed statement, monthly CSV export, filtered totals, optional-budget major head.
5. Reliable saving: Explicit success only after authenticated Google Sheets result, prevent double-click submission; failed form remains filled.
6. Accessibility: Control names, text alternatives, touch targets, color not the only data signal, keyboard navigation.
7. Performance: No third-party chart library or extra chart API calls; verify INP/LCP with real device and Apps Script data.
8. Security: No financial records in public GitHub, server-side authorization unchanged, admin timeout preserved.
9. Continuity: Save Sheet backup and old Code.gs before replacing any scripts; deployment version checked.
10. Restore: Existing user data untouched, no schema migration, no setupSystem.

Current ratings: not yet independently measured; a 9.5+ result is an acceptance goal rather than a guaranteed result.
