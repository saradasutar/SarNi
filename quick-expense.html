Install SarNi Quick Expense on your phone

Separate home-screen icon · opens directly to this form · no SarNi login required.

Android: use your browser menu → Install app / Add to Home screen. iPhone: Safari Share → Add to Home Screen. Keep the private shared link in case your phone requires it again.

This shortcut saves the private link on this device for convenience. Anyone using your unlocked phone can enter expenses through it while the link remains active. The administrator can disable it immediately.

Each link starts as Expense-only. Admin can separately allow Diary (including Investment Wisdom), Stock Diary, or a recent-entry preview; it never opens your other private records or account settings. The administrator can disable or re-enable the same link.
